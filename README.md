# JobTrack - Job Application Tracker

A professional React.js project for managing and tracking job applications.

## Features

- Add job applications
- Search applications
- Filter applications by status
- Track application status
- Delete applications
- Dashboard statistics
- Responsive design

## Technologies

- React.js
- JavaScript ES6+
- HTML5
- CSS3
- Vite
- Git and GitHub

## Run the Project

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
